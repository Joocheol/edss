# 데이터

- `raw/`: 수정하지 않는 다운로드 원본. Git에서 제외합니다.
- `interim/`: 정제·병합 중간 데이터. Git에서 제외합니다.
- `processed/`: 다음 분석에 투입하는 정제 데이터와 DuckDB. Git에서 제외합니다.
- `metadata/`: 출처·수집 기록·스키마·품질검사 결과. 기존 경로를 유지합니다.

수치·그림·표 등 보고할 분석 결과는 `outputs/`에, 결과 해석은
`docs/findings/`에 둡니다. 기존 수집·감사 기록과 분석 산출물은 출처 링크와
체크섬을 보존하기 위해 이번 구조 개편에서 이동하지 않았습니다.

상세 목록은 [메타데이터 안내](metadata/README.md)와
[데이터 구조](../docs/edss_panel_dataset.md)를 확인하세요.
