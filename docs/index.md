# EDSS v2

한국 고등교육 장기 패널을 처음부터 다시 구축하는 프로젝트입니다.

GitBook은 이 저장소의 `docs/` 전체를 문서 루트로 사용합니다. 현재 확인이 끝난
수집 범위부터 기록하고, 이후 추가되는 모든 연구 문서는 목차에 연결합니다.

핵심 수집원은 **EDSS 개방데이터, KESS 공개 데이터, 한국대학교육협의회
대학알리미 Open API 9종**으로 한정합니다. 공공데이터포털의 개별 파일데이터는
세 핵심 수집원에 없는 연구 필수 변수가 확인된 경우에만 예외적으로 추가합니다.

## 현재 상태

- EDSS 개방데이터: 주 분석 원본
- KESS 공개 데이터: 시계열·하반기 자료 보완 및 교차검증
- 한국대학교육협의회 대학알리미 Open API 9종·103개 기능: 실시간 검증 완료
- 공공데이터포털 개별 파일데이터: 정규 수집 범위에서 제외
