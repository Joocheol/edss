# EDSS 전체 패널 키·내용 감사

## 결론

233개 논리 패널의 180,119,183행을 전수 재검사했다. 파일·행 추적 구조에서 데이터 손상을 뜻하는 오류는 발견되지 않았다. 그러나 분석용 grain과 조인 측면에서는 검토가 필요하다. 211개 패널은 `(연도, 개방ID)`보다 세분된 차원을 요구하고, 취업통계 1개 패널의 2023–2024년 46,962행은 형식 단절 결정에 따라 기존 OpenID 종단 패널에서 제외한다. `0101 고등교육학교개황`을 원시 상태로 결합하면 반복 기준 키 때문에 229개 패널에서 이론상 30,192,638개의 추가 행이 생길 수 있다.

최종 상태는 `review_required`이며 심각도는 high 4개, medium 229개, critical 0개다. high는 데이터 손상이 아니라 `0101` 미연결률이 1%를 넘는 패널이다.

## 범위와 grain

- 대상: 고등교육통계 102개, 대학정보공시 130개, 취업통계 1개
- 기간: 패널별 관찰 범위, 전체적으로 2009–2025년
- 기준 연결키: `_panel_year`와 `개방ID`
- 기준 패널: 고등교육통계 `0101 고등교육학교개황`
- 검사 단위: 패널 행, 패널별 학교연도 키, 패널-연도, `0101` 연결 결과

## 무결성 검사

모든 gzip 출력을 다시 읽고 카탈로그 SHA-256을 확인했다. 열 폭 불일치, 결정적 행 ID 불일치, 잘못된 행 ID 형식, 중복 행 ID, 정규화된 전체 행 중복, 패널 연도 누락·형식 오류, 원본 조사년도 불일치는 모두 0건이었다. `개방ID` 공백·유니코드 정규화 충돌도 0건이다.

`_source_row_hash`는 각 원본 CSV 멤버의 당시 열 순서로 만들어졌지만 패널은 여러 시점 스키마의 합집합 열을 저장한다. 따라서 통합 패널만으로 원본 멤버의 열 순서를 복원할 수 있는 34,429,446행은 해시가 일치했고, 나머지 145,689,737행은 패널만으로 원본 해시를 재구성할 수 없는 것으로 분류했다. 이 수치는 손상 건수가 아니며 critical 판정에 포함하지 않았다. 원본 ZIP까지 다시 읽는 별도 소스-대-패널 감사가 필요할 때만 이 구간을 확정 검증할 수 있다.

## 주요 발견

### 분석 grain

- 211개 패널: `(연도, 개방ID)`에 학과·성별·과정·연령·항목 등 추가 차원이 필요
- 21개 패널: 비어 있지 않은 행에서 `(연도, 개방ID)`가 유일
- 1개 패널: 취업통계의 `개방ID` 부분 커버리지
- 전체 반복 학교연도 키: 1,232,385개
- 기본키만 사용할 때 중복으로 남는 행: 178,472,074행

반복은 대체로 원본 표의 세부 차원을 나타내며 중복 오류가 아니다. 패널별 `candidate_dimension_gains`는 최대 10,000행의 결정적 표본에서 계산한 후보 순위이므로 최종 키 확정 전 전수 유일성 검사가 필요하다.

### `개방ID` 완전성

233개 패널 모두 `개방ID` 열을 포함한다. 결측은 취업통계 `0001 학생인적취업정보`의 46,962행(0.6411%)에만 존재한다. 이는 2023–2024년 자료 구조 전환으로 해당 열이 제거된 구간이다. 학교명 기반 교차표가 확정되기 전에는 이전 연도 ID를 추정해 채우지 않는다.

### `0101` 미연결 키

전체 미연결은 3,322개 학교연도 키, 82,959행, 135개 패널이다. 시간적 분류는 다음과 같다.

| 분류 | 키 | 행 |
|---|---:|---:|
| `before_first_0101_year` | 1,668 | 18,198 |
| `after_last_0101_year` | 1,341 | 54,614 |
| `internal_0101_gap` | 217 | 9,033 |
| `never_in_0101` | 96 | 1,114 |

미연결률이 1%를 넘는 high 패널은 대학정보공시 `0202 대학입학전형기본계획_전문대학`(1.3373%), `0204 대학입학전형시행계획_전문대학`(1.3053%), `1102 도서관예산현황`(1.5466%), `1209 법인임원현황`(1.0640%)이다. 시간적 분류는 조사 범위 차이를 보여줄 뿐 신설·폐교·통폐합·ID 변경을 확정하지 않는다.

후속 전수 분류에서 `0202`의 26개 키·218행, `0204`의 12개 키·136행, `1102`의 35개 키·35행은 모두 해당 ID의 `0101` 관측기간 밖이었다. `1209`는 경계 키 66개와 내부 공백 1개로 나뉘며, 내부 공백은 2019년 OpenID `5831784427`의 16행이다. 앞의 세 패널은 미연결 상태를 보존하고 별도 ID 수정 없이 기간 범위 차이로 처리한다. `1209` 내부 공백은 공식 캠퍼스 연혁과 2019·2020년 행 연속성 검토를 거쳐 한국폴리텍Ⅱ대학 남인천캠퍼스의 학위과정 범위 공백으로 확정했다. 동일 ID와 16행을 보존하며 대입·보간하지 않는다. 고위험 패널 수동 검토 잔여는 0개다.

### 원시 `0101` 조인 증식

`0101`에는 30,556개의 학교연도 키가 있고 그중 1,187개가 반복되며 최대 반복 수는 4다. 이 기준표를 그대로 다른 패널에 결합하면 27,047,504개의 원본 행이 영향을 받고 이론상 30,192,638개의 추가 행이 생긴다. 229개 패널이 이 위험을 가진다.

## 사용 규칙

1. 원시 `0101` 대신 `data/metadata/edss_school_year_bridge.csv`를 사용한다. 이 기준표는 전체 233개 패널 180,119,183행에서 left join 행 증식 0으로 재검증됐다.
2. 패널별 분석 grain은 `candidate_dimension_gains`를 출발점으로 전수 유일성을 재검사해 확정한다.
3. 미연결 행을 삭제하거나 인접 연도의 ID로 강제 매핑하지 않는다.
4. 취업통계 2023–2024년은 `schema_break_excluded`로 확정해 `개방ID` 기반 장기 패널에서 제외한다. 원본과 안전 파생 자료는 독립 참고용으로 보존한다.
5. source row hash의 완전 검증이 필요하면 원본 ZIP의 멤버 헤더·행 번호를 다시 읽는 별도 검사를 수행한다.
