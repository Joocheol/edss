# 데이터 사용법

## 어떤 자료인가

주 자료는 EDSS 개방데이터입니다. 대학알리미 자료는 최신 정보 확인과 교차검증에 사용합니다. 전체 자료는 2009–2025년을 다루지만, 실제 이용 가능한 연도는 항목마다 다릅니다.

취업 분석에는 **2010–2020년 졸업 코호트, 학교–코호트 5,969개**로 정리한 데이터를 사용합니다. 파일에 적힌 연도와 졸업 코호트 연도는 다를 수 있습니다.

## 꼭 지킬 기준

- 원본은 수정하지 않습니다. 학교·학과 코드는 앞자리 0을 보존합니다.
- 결측, 비공개, 해당 없음, 실제 0을 구분합니다.
- 취업 추세는 **2010–2013년**과 **2014–2020년**을 나눠 비교합니다. 조사 기준일이 달라 2013→2014 증감은 비교하지 않습니다.
- 2015–2018년 코호트의 진학 지표는 사용하지 않습니다. 2023–2024년 취업 자료는 형식이 달라 기존 코호트 분석에서 제외했습니다.

분석용 자료는 맥의 `Documents/GitHub/edss/data/processed/`에 있습니다.
취업 분석의 기준 데이터는 `analysis.employment_cohort_school_2010_2020`입니다.

[세부 정의와 재현 방법은 GitHub에서 확인](https://github.com/Joocheol/edss/blob/main/docs/edss_employment_cohort_school_mart.md)
