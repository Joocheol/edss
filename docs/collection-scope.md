확인일: 2026-09-14 (Asia/Seoul)

이 문서는 실제 수집 대상으로 확정한 원천만 기록한다. 검색 결과에 나타난
후보나 추가 검토 중인 자료는 확정 전까지 포함하지 않는다.

|---|---:|---:|---|

| 대학정보공시 | 130 | 130 | 주로 2009–2025 |
| 취업통계 | 1 | 2 | 2010–2024 |
| **합계** | **233** | **265** | 항목별 상이 |

제공목록에 표시된 연도와 실제 다운로드 파일에서 관찰되는 연도는 별도로
기록한다. 논리 패널 수와 물리 다운로드 단위 수가 다른 것은 연도·스키마가
분리된 항목이 있기 때문이다.

`대학알리미`가 없는 대교협 공식 학과·학교 정보 API가 빠진다. 수집 범위는
검색 건수가 아니라 제공기관과 데이터 ID를 기준으로 고정한다.

## 아직 확정하지 않은 범위

공공데이터포털 파일데이터는 여러 검색 경로와 개별 상세 페이지를 다시
검증하고 있다. 기존 12개 후보를 확정 목록으로 승계하지 않으며, 선정 기준과
중복성 검토가 끝난 항목만 이 문서에 추가한다.

## 기록 원칙

- 원본 파일은 수정하지 않는다.
- 학교·캠퍼스·학과 코드는 앞자리 0을 보존하는 문자열로 읽는다.
- 제공목록 연도와 실제 관찰 연도를 따로 기록한다.
- 다운로드마다 출처 URL, 수집시각, 파일 크기, 행·열 수, SHA-256을 기록한다.
- 결측치, 비공개값, 해당 없음과 숫자 0을 구분한다.
- 인증키, 쿠키, 세션 정보와 개인정보는 저장소에 기록하지 않는다.
