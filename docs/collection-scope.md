# 확정 수집 범위

확인일: 2026-09-14 (Asia/Seoul)

이 문서는 실제 수집 대상으로 확정한 원천만 기록한다. 한국 고등교육기관
장기 패널의 핵심 수집원은 **EDSS 개방데이터, KESS 공개 데이터,
한국대학교육협의회 대학알리미 Open API 9종**으로 고정한다.

범위 수치는 2026-09-14에 다시 검토했다. EDSS는 저장소 이력에 보존된
2026-08-31 공식 목록과 완료 요약, KESS는 공식 학교/학과별 데이터셋 화면,
대학알리미는 공식 Swagger와 실제 응답을 근거로 한다. 기계 판독 가능한 확인
기록은 `data/metadata/source_scope_verification.json`에 남긴다.

## 1. EDSS 개방데이터

수집한다.

| 분야 | 논리 패널 | 물리 다운로드 단위 | 기본 연도 범위 |
|---|---:|---:|---|
| 고등교육통계 | 102 | 133 | 주로 2009–2025 |
| 대학정보공시 | 130 | 130 | 주로 2009–2025 |
| 취업통계 | 1 | 2 | 2010–2024 |
| **합계** | **233** | **265** | 항목별 상이 |

제공목록에 표시된 연도와 실제 다운로드 파일에서 관찰되는 연도는 별도로
기록한다. 논리 패널 수와 물리 다운로드 단위 수가 다른 것은 연도·스키마가
분리된 항목이 있기 때문이다.

## 2. KESS 공개 데이터

KESS(교육통계서비스)의 고등교육통계와 고등교육기관 졸업자 취업통계 공개
Excel 자료를 수집한다. KESS는 EDSS와 통계 생산 기반이 상당 부분 겹치므로
별개의 독립 통계로 합산하지 않고, 시계열 보완과 공개 파일 단위의
교차검증 자료로 사용한다.

| 분야 | 논리 시계열 | 물리 연도별 파일 | 공개 연도 범위 |
|---|---:|---:|---|
| 고등교육통계 | 7 | 104 | 항목별 2008–2026 |
| 졸업자 취업통계 | 3 | 42 | 2011–2024 |
| **합계** | **10** | **146** | 항목별 상이 |

고등교육통계 7개 시계열은 다음과 같다.

- 4월 1일 기준 학교별·학과별·학교×학과별 자료: 각각 2008–2026
- 10월 1일 기준 학교별·학과별·학교×학과별 자료: 각각 2015–2025
- 학교×국가별 외국인 유학생 자료: 2013–2026

취업통계 3개 시계열은 학교별·학과별·학교×학과별 자료이며, 각각
2011–2024년 파일이 공개되어 있다. KESS에서는 특히 EDSS의 기본 범위를
앞서는 2008년 자료, 최신 2026년 4월 자료, 하반기 시점 자료와 통합 파일을
보완한다.

- [KESS 고등교육통계 데이터셋](https://kess.kedi.re.kr/contents/dataset?itemCode=04&menuId=m_02_04_03_02&tabId=m2)
- [KESS 취업통계 데이터셋](https://kess.kedi.re.kr/contents/dataset?itemCode=04&menuId=m_02_04_03_02&tabId=m3)

논리 시계열 수와 물리 파일 수는 구분한다. 실제 수집 시에는 공개 화면의
표시 연도와 다운로드된 파일 내부의 기준연도·기준일을 각각 기록한다.

`대학알리미`가 없는 대교협 공식 학과·학교 정보 API가 빠진다. 수집 범위는
검색 건수가 아니라 제공기관과 데이터 ID를 기준으로 고정한다.

## 공공데이터포털 파일데이터 처리 원칙

공공데이터포털의 개별 파일데이터는 정규 수집 대상에서 제외한다. 다수 항목이
EDSS·KESS·대학알리미 API 자료의 재배포, 요약 또는 중복 자료이기 때문이다.
다만 세 핵심 수집원에 없고 연구에 반드시 필요한 변수가 확인되면 다음 조건을
모두 충족하는 경우에만 예외 수집원으로 추가한다.

- 연구 질문에 직접 필요한 변수여야 한다.
- 세 핵심 수집원으로 동일한 관측 단위와 기간을 구성할 수 없어야 한다.
- 제공기관, 갱신주기, 관측 단위, 키, 실제 파일 연도를 확인해야 한다.
- 기존 자료와의 중복 여부 및 연결 가능성을 대표 파일로 검증해야 한다.

따라서 현재 확정된 공공데이터포털 개별 파일데이터 수집 대상은 없다.

## 기록 원칙

- 원본 파일은 수정하지 않는다.
- 학교·캠퍼스·학과 코드는 앞자리 0을 보존하는 문자열로 읽는다.
- 제공목록 연도와 실제 관찰 연도를 따로 기록한다.
- 다운로드마다 출처 URL, 수집시각, 파일 크기, 행·열 수, SHA-256을 기록한다.
- 결측치, 비공개값, 해당 없음과 숫자 0을 구분한다.
- 인증키, 쿠키, 세션 정보와 개인정보는 저장소에 기록하지 않는다.
