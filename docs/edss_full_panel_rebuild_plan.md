# EDSS 전체 패널 재구성·개방ID 재감사 계획

기준일: 2026-09-01 (Asia/Seoul)

## 기준점

원본의 권위 순서는 EDSS 실시간 다운로드 목록, 기존 우선순위 원본 매니페스트, 전체 수집 시도 기록, 로컬 불변 ZIP 순이다. 실시간 목록은 다운로드 단위인 `domnCd`를 제공하지만 카탈로그 코드는 제공하지 않고, 최종 상태표는 ZIP 경로를 제공하지 않는다. 따라서 `domnCd`를 기준으로 두 다운로드 기록에서 카탈로그 코드와 ZIP provenance를 복원해야 전체 패널 입력을 재현할 수 있다.

`scripts/build_edss_full_rebuild_inventory.py`가 이 결합을 수행한다. 결과의 grain은 실시간 물리 다운로드 단위 한 행이며, `(분야, 카탈로그 코드, 테이블명)`으로 묶어 논리 테이블을 구성한다.

## 첫 안전 단위 결과

| 범위 | 논리 테이블 | 물리 단위 | ZIP |
|---|---:|---:|---:|
| 전체 수집 | 233 | 265 | 278 |
| 최초 우선 패널 파이프라인 | 15 | 16 | 29 |
| 최초 파이프라인 밖 | 218 | 249 | 249 |

전체 원본은 1,314,494,214 bytes다. 278개 파일의 존재, 기록된 크기, SHA-256을 실제 파일에서 다시 계산했으며 불일치와 누락은 0건이다.

분야별 범위는 다음과 같다.

| 분야 | 논리 테이블 | 물리 단위 | ZIP |
|---|---:|---:|---:|
| 고등교육통계 | 102 | 133 | 133 |
| 대학정보공시 | 130 | 130 | 130 |
| 취업통계 | 1 | 2 | 15 |

32개 논리 테이블은 연도·스키마 전환 때문에 물리 단위가 둘이다. 예를 들어 고등교육통계 `개설교과현황`은 2009~2013년과 2014~2022년 다운로드 단위로 나뉜다. 취업통계 `학생인적취업정보`는 2010~2022년과 2023~2024년 스키마 단위로 나뉘고, 실제 원본은 연도별 15개 ZIP이다. 이 분할은 중복이 아니라 논리 패널 구성 시 함께 처리해야 하는 입력이다.

`build_edss_dataset.py`는 전체 인벤토리의 명시적 ZIP 경로와 SHA-256을 읽고 사전검사 프로필을 대조한다. 기존 정상 출력은 체크섬 검증 후 재사용하며, 대형 표의 정확 중복 검출은 SHA-256 행 해시를 64개 디스크 파티션으로 나눠 메모리 사용량을 제한한다.

## 실행 단위

1. **전체 입력 고정 — 완료.** 233개 논리 테이블, 265개 물리 단위, 278개 ZIP을 하나의 인벤토리로 결합하고 현재 파이프라인 범위를 표시한다. 누락·상태 불일치·코드 불일치·파일 크기·SHA-256 오류는 구조화된 `issues` 목록과 실패 종료 상태로 남긴다.
2. **전체 스키마 사전검사 — 완료.** 빌더가 인벤토리의 ZIP 경로를 직접 읽도록 만들고, 출력 패널을 쓰기 전에 모든 ZIP·중첩 ZIP·CSV의 인코딩, 헤더, 연도, 행 길이, 행 수를 스트리밍 검사한다. 예외는 분야·테이블·연도·`domnCd`·ZIP·내부 멤버까지 기록한다.
3. **233개 논리 패널 재구성 — 완료.** 원본 값을 문자열로 보존하고 32개 분할 테이블을 논리 단위로 합쳤다. 원본 ZIP, 내부 멤버, 원본 행 번호, 행 해시를 보존한다. 취업통계의 개인 수준 자료는 제한 경로를 유지하며 일반 패널과 섞지 않는다.
4. **독립 재검산 — 출력 무결성 완료, 행 내용 재감사 예정.** 233개 출력의 존재·크기·SHA-256을 빌드 후 전체 파일 재읽기로 검증했고 카탈로그와 프로필의 행 수 합계가 사전검사 180,119,183행과 일치했다. 다음 실행 단위에서 gzip 행·열 수, 관찰 연도, 정확 중복, 식별자 결측을 출력에서 다시 계산한다.
5. **개방ID 의미 전수조사.** 233개 테이블에서 `개방ID`와 다른 학교·캠퍼스·대학원·학과 식별자 열의 출현, 결측, cardinality, 함께 나타나는 명칭·단위 열을 조사한다. `개방ID`가 모든 테이블에서 같은 grain을 뜻한다고 가정하지 않고, 테이블별 후보키와 반복 차원을 먼저 확정한다.
6. **중복·불일치·고아 키 재감사.** 확정된 grain별로 정확 중복, 후보키 중복, 정규화 후 근접 중복, 이름·지역·본분교 속성 충돌, 연도별 출현 공백, 기준표 미연결을 구분한다. 기존 15개 패널의 76개 미연결 키 결과는 비교 자료로만 사용하고 전체 결과로 승계하지 않는다.
7. **사람이 검증할 수 있는 사례와 노트북.** 사례마다 연도, 분야, 테이블, 학교급, 학교·캠퍼스·학과 명칭과 원본 provenance를 함께 제시한다. 전체 실행 노트북은 스크립트를 호출하고 핵심 수량과 예외 표를 재검산하며, 코드와 저장된 산출물의 체크섬을 남긴다.

각 실행 단위는 테스트와 실제 입력 검증이 모두 통과한 뒤 Git 상태를 확인하고 별도 커밋으로 `main`에 추가한다. 원본 ZIP과 대용량 패널은 계속 Git에서 제외한다.

## 전체 스키마 사전검사 결과

전체 265개 물리 단위의 278개 ZIP에서 CSV 멤버 1,142개와 데이터 행 180,119,183개를 읽었다. 읽기 실패, CSV 헤더 폭과 다른 행, 빈 스키마는 0건이므로 전체 패널 빌드를 시작할 수 있다.

분야별 행 수는 고등교육통계 147,761,413행, 대학정보공시 25,032,821행, 취업통계 7,324,949행이다. 물리 단위 내부에서 헤더가 둘 이상인 경우가 26개이고, 연도 분할 물리 단위를 합쳐 논리 테이블 관점에서 스키마 변형이 있는 경우가 58개다. 변형 열은 제거하거나 추정하지 않고 각 헤더와 적용 멤버를 저장했다.

제공 연도와 실제 행의 조사년도가 다른 물리 단위는 4개다.

| 분야 | 코드 | 테이블 | 제공 연도 | 실제 관찰 연도 | 판정 |
|---|---|---|---|---|---|
| 고등교육통계 | 0222 | 재적학생현황_대학원_공동운영 | 2010~2023 | 2010~2013 | 2014~2023 실제 행 없음 |
| 고등교육통계 | 0314 | 교원급여및수업시수현황 | 2009~2014 | 2009~2013 | 2014 실제 행 없음 |
| 고등교육통계 | 0317 | 교원현황_산업대학 | 2014~2022 | 2014~2016, 2020~2022 | 2017~2019 실제 행 없음 |
| 고등교육통계 | 0405 | 사이버강좌개설및수강현황_전문대학 | 2014~2022 | 2014~2025 | 2023~2025 실제 행이 제공 범위보다 넓음 |

`개방ID`는 265개 물리 단위 중 264개에 있다. 유일한 예외는 취업통계 `학생인적취업정보`의 2023~2024년 구조(`domnCd` 13300)다. 이 구조는 학교명·본분교명·학과명은 포함하지만 `개방ID`나 다른 코드 열은 포함하지 않는다. 2010~2022년 구조(`domnCd` 13299)는 `개방ID`를 포함한다. 따라서 전체 개방ID 감사에서 2023~2024년 취업 자료를 ID 기준으로 강제 연결하지 않는다.

## 전체 패널 빌드 결과

233개 논리 패널의 총행 수는 180,119,183행이며 압축 출력은 17,000,115,337 bytes다. 일반 패널 232개는 `data/processed/edss/panel/`에, 민감 가능 열이 있는 취업통계 1개는 `data/processed/edss/restricted/`에 저장했다. 빌드 종료 후 임시 `.part` 파일과 행 해시 디렉터리는 0개였다.

| 분야 | 논리 패널 | 행 | 압축 bytes |
|---|---:|---:|---:|
| 고등교육통계 | 102 | 147,761,413 | 13,785,638,593 |
| 대학정보공시 | 130 | 25,032,821 | 2,467,051,900 |
| 취업통계 | 1 | 7,324,949 | 747,424,844 |

가장 큰 패널은 고등교육통계 `0230 지원자및입학현황`으로 37,847,580행, 3,529,253,771 bytes다. 최초 15개 패널은 재사용 전후의 행 수와 출력 SHA-256이 모두 같았다. 전체 233개 출력도 빌드와 독립된 파일 재읽기에서 카탈로그 SHA-256과 전부 일치했고, 카탈로그와 233개 `profile.json` 사이의 경로·행 수·크기·체크섬 불일치는 0건이다.
