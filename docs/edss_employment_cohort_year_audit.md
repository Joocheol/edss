# EDSS 취업통계 코호트 연도 감사

기준 실행일: 2026-09-04

## 기술 요약

EDSS `학생인적취업정보`의 2010–2022년 파일 연도는 졸업 코호트 연도로 직접 사용할 수 없다. 7,277,987행의 `졸업년월`을 7–12월은 다음 해, 1–6월은 같은 해의 졸업 코호트로 배정하고 가중 최빈 코호트를 산출한 결과, 13개 파일 연도는 2010–2020년 11개 코호트만 포함한다.

분석에 바로 사용할 수 있는 파일 연도는 10개다. 2010–2013년은 파일 연도와 코호트 연도가 같고, 2016–2020년은 코호트 연도로 1년 앞당겨야 한다. 2021년은 2020 코호트의 첫 제공본으로 보존해 코호트 연도를 2020으로 바꿀 수 있다. 2022년은 같은 2020 코호트의 학교 집계가 2021년과 전부 같으므로 제외한다. 2014·2015년은 모두 2014 코호트지만 서로 다른 파동이므로 조사 기준일을 확정하기 전에는 어느 쪽도 자동 선택하지 않는다.

## 반복 코호트는 성격이 다르다

| 코호트 | 파일 연도 | 공통 OpenID | 학교 집계 완전 일치 | 졸업월 분포 | 처리 |
|---:|---|---:|---:|---|---|
| 2014 | 2014·2015 | 552 | 20개(3.623%) | 다름 | 서로 다른 조사 파동으로 보고 기준일 확인 전 보류 |
| 2020 | 2021·2022 | 537 | 537개(100%) | 동일 | 2021년 보존, 2022년 제외 |

2014·2015년은 행 수가 2개 차이뿐이지만 552개 학교 중 532개의 12개 집계 벡터가 다르다. KEDI 자료는 2012년부터 6월 1일·12월 31일 기준 연 2회 조사했고 2015년부터 12월 31일 기준 조사로 일원화했다고 설명한다. 이 방법론 전환은 두 파일이 같은 코호트의 서로 다른 관측 파동일 가능성을 지지하지만, 각 EDSS 파일과 기준일의 직접 대응은 확인되지 않았으므로 자동 선택하지 않는다. [KEDI 관련조사 및 자료](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1012636&publItemId=69896)

2021·2022년은 원본 `조사년도` 값만 다르고 졸업월 분포와 모든 학교 집계가 같다. 공식 2021년 조사는 2020년 8월·2021년 2월 졸업자, 공식 2022년 조사는 2021년 8월·2022년 2월 졸업자를 대상으로 하지만 같은 이름의 EDSS 파일에는 해당 월이 각각 0건이다. 따라서 `_panel_year`는 공식 조사연도나 졸업 코호트가 아니라 원본 제공 라벨로만 보존한다. [KEDI 2021년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1064949&publItemId=95638), [KEDI 2022년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1075201&publItemId=102507)

## 범위와 정의

- 원천: 제한 DuckDB의 `analysis.employment_legacy_2010_2022`
- 원천 grain: 졸업자 수준 7,277,987행
- 감사 CSV grain: 파일 연도당 한 행, 총 13행
- 학교 비교 grain: `(파일 연도, OpenID)`
- 학교 비교 벡터: 원천 행 수와 11개 원천 보고 지표
- 추론 코호트: 유효한 `졸업년월`을 7–12월이면 다음 해, 1–6월이면 같은 해로 매핑한 뒤 행 수 기준 최빈 연도
- 주요 졸업월 비중: 추론 코호트 직전 8월과 해당 연도 2월 행 수를 파일 전체 행 수로 나눈 값

`졸업년월` 공백·형식 오류는 13개 연도 모두 0건이고, 원본 `조사년도`가 파일 연도와 다른 행도 0건이다. 최빈 코호트가 차지하는 비중은 모든 연도에서 99.932% 이상이므로 소수의 비정규 졸업월이 코호트 판정을 바꾸지 않는다.

## 재현 방법과 검증

```bash
uv run --with duckdb==1.4.1 python scripts/audit_edss_employment_cohort_years.py
```

스크립트는 제한 DB를 읽기 전용으로 열고 개인식별번호·회사명·논문명·개별 행을 출력하지 않는다. 결과는 연도별 수와 학교 집계 비교 건수로 제한한다.

- 연도별 품질표: `data/metadata/edss_employment_cohort_year_audit.csv`
- 감사 요약: `data/metadata/edss_employment_cohort_year_audit.json`
- 검산 노트북: `notebooks/edss_employment_cohort_year_audit.ipynb`
- 재현 스크립트: `scripts/audit_edss_employment_cohort_years.py`
- 합성 회귀 테스트: `tests/test_audit_edss_employment_cohort_years.py`

독립 검산은 원천 행 수 7,277,987, 파일 연도 13개, 코호트 11개, 반복 코호트 2개, 분석 후보 파일 연도 10개를 확인한다. 2021–2022년 비교는 537개 OpenID 전부의 집계 일치와 졸업월 분포 일치를 다시 검사한다.

## 제한과 다음 결정

이번 감사는 실제 졸업월에 근거한 기술적 코호트 정렬이며, 제공기관이 `_panel_year`를 어떤 행정적 의미로 부여했는지는 확정하지 않는다. 특히 2014·2015년 중 어느 파일이 2014 코호트의 최종 분석 파동인지 선택하려면 두 ZIP의 조사 기준일을 직접 확인해야 한다.

다음 단계는 이 감사표를 입력으로 삼아 안전한 코호트 뷰를 만드는 것이다. 그 전에 2014·2015년 기준일을 확인해 한 파동을 승인하거나, 둘 다 별도 `observation_wave`로 유지하는 결정을 기록해야 한다.
