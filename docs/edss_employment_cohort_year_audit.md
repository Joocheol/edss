# EDSS 취업통계 코호트 연도 감사

기준 실행일: 2026-09-04

## 기술 요약

EDSS `학생인적취업정보`의 2010–2022년 파일 연도는 졸업 코호트 연도로 직접 사용할 수 없다. 7,277,987행의 `졸업년월`을 7–12월은 다음 해, 1–6월은 같은 해의 졸업 코호트로 배정하고 가중 최빈 코호트를 산출한 결과, 13개 파일 연도는 2010–2020년 11개 코호트만 포함한다.

공식 조사 전환표와 원천 합계를 대조해 2014 코호트의 두 파동도 해소했다. 2014 파일은 2014년 6월 1일 기준 파동이고, 2015 파일은 같은 졸업 코호트의 2014년 12월 31일 기준 파동이다. 후속 계열과 같은 연말 기준인 2015 파일을 선택한다. 따라서 분석에 사용할 원천은 11개다. 2021년은 2020 코호트의 첫 제공본으로 보존하고, 2022년은 같은 2020 코호트의 완전 반복이라 제외한다.

막대나 선 그래프는 사용하지 않았다. 파일 연도와 코호트 연도가 중간에 어긋나고 두 코호트가 반복되므로, 연속 추세처럼 그리면 이번 감사에서 경고하려는 시간축 오류를 오히려 숨길 수 있다. 정확한 대응표가 판단에 더 적합하다.

## 반복 코호트는 성격이 다르다

| 코호트 | 파일 연도 | 공통 OpenID | 학교 집계 완전 일치 | 졸업월 분포 | 처리 |
|---:|---|---:|---:|---|---|
| 2014 | 2014·2015 | 552 | 20개(3.623%) | 다름 | 6월 파동 제외, 12월 파동 선택 |
| 2020 | 2021·2022 | 537 | 537개(100%) | 동일 | 2021년 보존, 2022년 제외 |

2014·2015년은 행 수가 2개 차이뿐이지만 552개 학교 중 532개의 12개 집계 벡터가 다르다. KEDI 전환표는 2014년에 6월 1일 건강보험 DB 조사와 12월 31일 건강보험·국세 DB 조사가 함께 존재했으며 이후 연말 기준으로 일원화되었음을 보여 준다. 원천 2014 파일의 졸업자 557,236명은 6월 파동 공식 합계와 일치한다. 원천 2015 파일의 졸업자 557,234명과 `취업자수` 302,280명은 KEDI가 발표한 2014년 12월 31일 결과의 졸업자와 직장건강보험 가입자 합계에 각각 정확히 일치한다. 따라서 단순 추정이 아니라 기준일과 합계가 함께 맞는 파동 판정으로 확정했다. [KEDI 조사 전환표](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1032483&publItemId=79838), [KEDI 2014년 12월 31일 조사 발표](https://www.kedi.re.kr/khome/main/announce/selectBroadAnnounceForm.do?article_sq_no=30069&board_sq_no=3&currentPage=0&doc_use_yn=N&selectTp=0)

2021·2022년은 원본 `조사년도` 값만 다르고 졸업월 분포와 모든 학교 집계가 같다. 공식 2021년 조사는 2020년 8월·2021년 2월 졸업자, 공식 2022년 조사는 2021년 8월·2022년 2월 졸업자를 대상으로 하지만 같은 이름의 EDSS 파일에는 해당 월이 각각 0건이다. 따라서 `_panel_year`는 공식 조사연도나 졸업 코호트가 아니라 원본 제공 라벨로만 보존한다. [KEDI 2021년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1064949&publItemId=95638), [KEDI 2022년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1075201&publItemId=102507)

## 범위와 정의

- 원천: 제한 DuckDB의 `analysis.employment_legacy_2010_2022`
- 원천 grain: 졸업자 수준 7,277,987행
- 감사 CSV grain: 파일 연도당 한 행, 총 13행
- 학교 비교 grain: `(파일 연도, OpenID)`
- 학교 비교 벡터: 원천 행 수와 11개 원천 보고 지표
- 추론 코호트: 유효한 `졸업년월`을 7–12월이면 다음 해, 1–6월이면 같은 해로 매핑한 뒤 행 수 기준 최빈 연도
- 주요 졸업월 비중: 추론 코호트 직전 8월과 해당 연도 2월 행 수를 파일 전체 행 수로 나눈 값

`졸업년월` 공백·형식 오류는 13개 연도 모두 0건이고, 원본 `조사년도`가 파일 연도와 다른 행도 0건이다. 최빈 코호트가 차지하는 비중은 모든 연도에서 99.932% 이상이므로 소수의 비정규 졸업월이 코호트 판정을 바꾸지 않는다.

## 재현 방법과 검증

```bash
uv run --with duckdb==1.4.1 python scripts/audit_edss_employment_cohort_years.py
```

스크립트는 제한 DB를 읽기 전용으로 열고 개인식별번호·회사명·논문명·개별 행을 출력하지 않는다. 결과는 연도별 수와 학교 집계 비교 건수로 제한한다.

- 연도별 품질표: `data/metadata/edss_employment_cohort_year_audit.csv`
- 감사 요약: `data/metadata/edss_employment_cohort_year_audit.json`
- 검산 노트북: `notebooks/edss_employment_cohort_year_audit.ipynb`
- 재현 스크립트: `scripts/audit_edss_employment_cohort_years.py`
- 합성 회귀 테스트: `tests/test_audit_edss_employment_cohort_years.py`

독립 검산은 원천 행 수 7,277,987, 파일 연도 13개, 코호트 11개, 반복 코호트 2개, 최종 선택 원천 11개를 확인한다. 2014·2015년은 기준일·공식 합계와 선택 상태를, 2021–2022년은 537개 OpenID 전부의 집계 및 졸업월 분포 일치를 다시 검사한다.

## 남은 제한

이번 감사는 실제 졸업월, 공식 기준일 체계, 공식 총계에 근거한 기술적 코호트 정렬이다. `_panel_year`라는 EDSS 제공 라벨의 행정적 생성 규칙과 2021·2022년 파일의 공식 조사연도 불일치 원인은 제공기관 설명이 없어 확정하지 않는다.

최종 `analysis.employment_cohort_school_2010_2020`은 2014·2022 파일을 삭제하지 않고 원천 계층에 보존하면서 분석 선택에서만 제외한다. 다만 2010–2013 코호트는 6월 1일 기준이고 2014–2020 코호트는 12월 31일 기준이므로, 2013↔2014 변화를 동일 정의의 추세로 해석하면 안 된다. 구현과 검증은 `docs/edss_employment_cohort_school_mart.md`에 기록한다.
