# EDSS 우선순위 미연결 ID 학교이력 검증

기준일: 2026-09-01 (Asia/Seoul)

## 결론

`0101 고등교육학교개황`에 연결되지 않은 우선순위 6개 학교연도 ID를 통폐합·폐교·명칭 변경·학위과정 중단·ID 승계 관점에서 다시 검토했다. 이 6개를 일괄적으로 데이터 오류나 폐교로 분류하면 안 된다.

| 연도 | 개방ID | 판정 | 변화 유형 | 안전한 처리 |
|---:|---|---|---|---|
| 2009 | `4124740779` | 서울시립대 디자인전문대학원의 구 ID 가능성 | 대학원 명칭 변경 | 확정 매핑 금지, 수동 후보표 유지 |
| 2009 | `5814962685` | 서울시립대 세무전문대학원의 구 ID 가능성 | 대학원 명칭 변경 | 확정 매핑 금지, 수동 후보표 유지 |
| 2009 | `6566148042` | 동서대 일반대학원 하위 ID 중복 가능성 | 중복·과거 대학원 하위 ID | 확정 매핑 금지, 수동 후보표 유지 |
| 2015 | `5831784427` | 한국폴리텍Ⅱ대학 남인천캠퍼스 | 학위과정 중단·재개 | 동일 ID 유지, 2015 공백 플래그 |
| 2016 | `9080059170` | 명지대학교 사회복지대학원의 중복·교원유형 재분류 ID가 유력 | 중복 행·교원유형 재분류 | 수동 후보표 유지, 자동 치환 금지 |

## 주요 근거

### `5831784427`: 폐교가 아니라 학위과정 범위의 중단·재개

- `0101`에서는 인천의 기능대학으로 2010~2014년과 2020~2025년에 동일 ID가 관측된다.
- 2015년 `0316`과 `1016`에는 폐과 상태의 `인쇄정보미디어과`가 각각 1행 남아 있다.
- 2020년 이후에는 `스마트표면처리과`, `스마트전기과(ICT융합제어)`가 같은 ID로 나타난다.
- 학과명과 미추홀구 소재지는 한국폴리텍Ⅱ대학 남인천캠퍼스와 일치한다.
- [남인천캠퍼스 공식 연혁](https://kopo.ac.kr/namincheon/content.do?menu=7003)은 캠퍼스가 계속 존속했으며 2019년 전문기술과정 입학, 2020년 2년제 학위과정 신설을 기록한다.

따라서 2015~2019년 `0101` 공백은 학교 자체의 폐교가 아니라 고등교육 패널에 포함되는 학위과정의 중단 후 재개로 해석하는 것이 가장 타당하다. 2015년 행은 이전 폐과의 잔존 기록이므로 삭제하거나 2020년 값으로 보간하지 않는다.

### `4124740779`, `5814962685`: 서울시립대 대학원 명칭 변경의 구 ID 가능성

- 두 ID는 2009년 `0502`에 각각 `산업디자인학과`, `세무학과` 1행만 있고 모든 교원값이 0이다.
- 같은 연도 `0101`에 연결되는 동대문구 대학원 ID `5744977414`는 산업디자인학과만, `6187031745`는 세무학과만 보유한다.
- [서울시립대 세무전문대학원 공식 연혁](https://wifi.uos.ac.kr/gtaxNew/html/intro/history.do?menuid=3002001005000000000)은 2008년 11월 `세무대학원`이 `세무전문대학원`으로 바뀌었다고 명시한다.
- [서울시보 제2892호](https://event.seoul.go.kr/seoulsibo/fileDownload.do?fileName=%EC%A0%9C2892%ED%98%B8.pdf)는 같은 시기 `디자인대학원`과 `세무대학원`이 각각 전문대학원으로 명칭 변경되었음을 기록한다.

기관·학과·시점이 일치하므로 구 명칭 ID가 `0502`에 잔존했을 가능성이 높다. 그러나 EDSS가 개방ID-학교명 공식 교차표를 제공하지 않았으므로 두 ID를 정상 ID에 자동 치환하지 않는다.

### `6566148042`: 동서대 일반대학원 중복 하위 ID 가능성

- 2009년 디자인·소프트웨어·영상콘텐츠·유비쿼터스IT 4개 학과로 구성된다.
- 정상 ID `7397292733`은 부산 사상구 대학원이며 이 4개 학과와 유비쿼터스네트워크공학과를 보유한다.
- 4개 학과가 모두 겹치고 일부 원시 행은 ID를 제외하면 완전히 동일하다.
- [동서대 일반대학원 공식 모집자료](https://uni.dongseo.ac.kr/graduategeneral/index.php?idx=31&mode=fdn&num=1&pCode=MN8000063&pg=57)에서 영상콘텐츠학과와 유비쿼터스IT학과를, [동서대 대학·대학원 안내](https://www.dongseo.ac.kr/kr/index.php?pCode=dsuuni)에서 부산 사상구 소재와 일반대학원 학과 구성을 확인할 수 있다.

이는 폐교·통폐합보다는 원천에서 과거 대학원 하위 ID 또는 중복 ID가 함께 출력된 사례에 가깝다. 역시 공식 교차표 없이는 자동 통합하지 않는다.

### `9080059170`: 명지대 사회복지대학원의 중복·교원유형 재분류 ID가 유력

- 원시 행은 2016년 `사회복지학과` 1행이며 전임교원은 모두 0, 시간강사는 남자 5명·여자 3명이다.
- 같은 2016년 정상 ID `2529507696`도 `사회복지학과` 1행이고 비전임교원이 남자 5명·여자 3명으로 정확히 같다. 차이는 이 8명이 `시간강사`가 아니라 `기타비전임` 칸에 기록됐다는 점뿐이다.
- 2016년 모든 대학원 사회복지학과를 성별 비전임교원 합계로 비교하면 `(남 5, 여 3)` 조합은 이 두 ID에만 나타난다.
- 정상 ID `2529507696`은 `0101`에서 서울 서대문구·제2캠퍼스·대학원으로 연결된다. 대학알리미 2016 공식 목록에서 이 조건과 `사회복지학과` 단일 학과를 동시에 만족하는 학교는 `명지대학교 사회복지대학원`이다.
- [명지대 2016학년도 특수대학원 모집자료](https://www.mju.ac.kr/bbs/mjukr/163/16184/download.do)도 서울 인문캠퍼스의 사회복지대학원·사회복지학과 운영을 확인한다.

따라서 `명지대학교 사회복지대학원`을 유력 후보로 수정한다. `9080059170`은 폐교·통폐합 잔존 ID라기보다 같은 교원 8명이 다른 비전임 유형으로 중복 집계된 ID일 가능성이 더 높다. 다만 EDSS 개방ID-학교명 직접 교차표는 없으므로 자동 치환하지 않는다.

### `2957261025`: 남부대 보건경영대학원이 유력

- 원시 행은 2019년 `간호학과` 1행이고 모든 교원값이 0이다.
- [대학알리미 2019년 학교별 학과목록](https://www.academyinfo.go.kr/brd/brd0520/selectDetail.do?bbs_gubun=rfbr&no=1&ntce_sntc_sno=89)은 남부대 보건경영대학원의 간호학과를 폐과로 기록한다.
- 같은 광주 광산구의 정상 ID `7710297405`는 간호학과·물리치료학과·방사선학과 3개로 구성되어 공식 목록의 `남부대학교 보건대학원`과 정확히 분리된다.
- 또 다른 정상 ID `7101625859`는 사회복지학과·한국어교육학과 등을 포함해 후속 문화복지 계열과 맞는다.
- 남부대 보건경영대학원 간호학과의 2019년 2월 학위논문이 확인되므로, 2019년은 실제 운영 종료·명칭 재편의 경계연도로 볼 수 있다. [남부대 현재 대학원 안내](https://graduate.nambu.ac.kr/content/view.do?menuCd=dept_gradu005001)도 `문화복지대학원(보건경영대학원)`이라는 승계 관계를 표시한다.

따라서 `남부대학교 보건경영대학원`을 유력 후보로 기록한다. 가천대 행정대학원, 남부대 보건대학원, 부산가톨릭대 생명과학대학원에도 폐과 간호학과가 있으므로 역시 공식 ID 교차표 전에는 자동 치환하지 않는다.

## 뉴스·신문 교차검증

- [아시아투데이 2013년 기사](https://www.asiatoday.co.kr/kn/view.php?key=845704)와 [아주경제 2014년 기사](https://www.ajunews.com/view/20140225131941975)는 신흥대와 한북대가 통합해 2014년 신한대로 출범했음을 확인한다. 한북대 지식복지대학원은 실제 통폐합 검토 대상이 맞지만, `9080059170`과 같은 해 정상 ID의 지역·교원수 중복이 명지대 쪽을 더 강하게 지지한다.
- [경향신문 2012년 기사](https://www.khan.co.kr/article/201205202157265)는 이화여대가 사회복지전문대학원 체제에서 일반·특수대학원 체제로 복귀한다고 보도한다. 이화여대도 폐지 대학원 후보였지만, 2016년 익명 행과 직접 연결되는 수치 증거는 없다.
- [헤드라인제주 2015년 기사](https://www.headlinejeju.co.kr/news/articleView.html?idxno=230613)는 제주국제대 사회복지임상치료대학원이 2015학년도에 실제 모집 중이었음을 확인한다. 제주국제대의 명칭 변경 이력은 사실이나, 이것만으로 `9080059170`을 제주국제대 구 ID로 볼 수는 없다.
- `2957261025`에 대해서는 보건경영대학원→문화복지대학원 관계를 직접 설명하는 동시대 신문기사를 찾지 못했다. 다만 [국회도서관 검색기록](https://dl.nanet.go.kr/search/searchInnerList.do?bestMeterialSearchQuery=%EB%82%A8%EB%B6%80%EB%8C%80%ED%95%99%EA%B5%90+%EB%B3%B4%EA%B1%B4%EA%B2%BD%EC%98%81%EB%8C%80%ED%95%99%EC%9B%90%3AALL_NI_TOC%3AAND&branchCode=ALL&dpBranch=ALL&hanjaYn=Y&navigationSize=5&nopMenu=REFD&orderBy=WEIGHT&pageNum=2&pageSize=10&queryText=%EB%82%A8%EB%B6%80%EB%8C%80%ED%95%99%EA%B5%90+%EB%B3%B4%EA%B1%B4%EA%B2%BD%EC%98%81%EB%8C%80%ED%95%99%EC%9B%90%3APUB%5EPUB_WS%5EDP_PUB_WS%3AAND&refineSearchYn=N&resultType=INNER_SEARCH_LIST&rspTime=0.556&searchClass=S&searchQuery=%EB%82%A8%EB%B6%80%EB%8C%80%ED%95%99%EA%B5%90+%EB%B3%B4%EA%B1%B4%EA%B2%BD%EC%98%81%EB%8C%80%ED%95%99%EC%9B%90&searchType=INNER&seqNo=0&totalSize=188&totalSizeByMenu=188&userClass=0&zone=PUB%5EPUB_WS%5EDP_PUB_WS)는 2019년 2월 남부대 보건경영대학원 간호학과 석사논문을 확인하므로 경계연도 잔존 판정은 유지한다.

## 결합 규칙 반영

1. `5831784427`은 동일 ID로 유지하고 2015년을 `_0101_match_status=degree_program_gap`으로 표시한다.
2. 나머지 5개 `open_id_absent_all_years`는 원본 ID를 보존한다.
3. 가능성이 높은 5개 후보 매핑은 `probable` 수동 검토표에만 두고 분석용 자동 조인에는 사용하지 않는다.
4. 학교 통폐합·명칭 변경 매핑에는 `predecessor_name`, `successor_name`, `effective_date`, `evidence_url`, `mapping_status`를 별도 필드로 둔다.
5. 폐교와 학위과정 중단을 같은 상태로 합치지 않는다.
