# EDSS 취업통계 학교–연도 마트

기준 실행일: 2026-09-04

## 기술 요약

2010–2022년 제한 취업통계 7,277,987행을 먼저 `(연도, OpenID)` 7,058개 유일키로 집계하고, 학교–연도 핵심 마트 24,044행에 left join한다. 취업 원천의 모든 키는 핵심 마트에 연결되며, 결합 후에도 24,044행·24,044개 유일키가 유지된다. 개인식별번호·회사명·논문명 등 개인형 열은 새 마트와 결합 뷰에 포함하지 않는다.

두 품질 이상 때문에 이 결과는 그대로 연도 추세나 공식 취업률로 해석할 수 없다. 2022년 537개 학교는 2021년과 11개 보고 지표 및 원천 레코드 수가 모두 동일하고, 실제 졸업년월도 공식 2022년 조사대상과 일치하지 않는다. 따라서 `employment_time_comparison_eligible=false`로 표시한다. `진학자수`는 2016–2019년 모든 행에서 0이므로 해당 연도의 진학 지표는 `all_zero_source_field` 상태로 표시한다. 공식 취업률은 정의하지 않는다.

## 2022년은 공식 코호트 정의와 충돌하므로 제외한다

2021년과 2022년은 각각 553,521개 원천 레코드와 537개 학교 키를 가진다. 같은 OpenID 537개 전체에서 원천 레코드 수와 다음 11개 집계 지표가 정확히 일치한다.

- 졸업학생, 취업자, 건강보험 취업자, 교내 취업자
- 진학자, 입대자, 취업불가능자, 외국인유학생
- 제외인정자, 기타 총계, 미상

개인식별번호는 두 해에 겹치지 않지만 졸업년월 분포와 학교별 집계 벡터가 동일하다. 두 파일의 원본 `조사년도`는 각각 2021년과 2022년으로 채워져 있으나, 2022년 파일의 졸업년월은 `201903`–`202003`이고 99.178%가 `201908` 또는 `202002`다. 교육부와 KEDI의 공식 2022년 조사대상인 2021년 8월·2022년 2월 졸업자는 원본에 0건이다.

공식 자료는 2021년 조사와 2022년 조사를 서로 다른 졸업 코호트로 정의한다. [KEDI 2021년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1064949&publItemId=95638)는 2020년 8월·2021년 2월 졸업자를, [KEDI 2022년 취업통계연보](https://kess.kedi.re.kr/publ/fileDownload.do?fileSeq=1075201&publItemId=102507)와 [교육부 2022년도 조사 지침](https://www.moe.go.kr/boardCnts/view.do?boardID=337&boardSeq=94792&lev=0&m=0303&s=moe)은 2021년 8월·2022년 2월 졸업자를 대상으로 명시한다. 확인한 공식 자료에는 EDSS 2022년 파일이 이전 코호트의 재공개라는 설명이 없다.

따라서 확인된 사실은 `공식 재공개`가 아니라 `공식 코호트 정의와 원본 내용의 충돌`이다. 2022년 행을 삭제하거나 2021년으로 덮어쓰지 않고 원값과 조사연도를 보존하되, 독립 2022년 코호트·시계열 분석에는 사용하지 않는다. 상세 근거와 체크섬은 `data/metadata/edss_employment_2022_official_verification.json`에 기록했다.

## 집계 정의와 검증

`analysis.employment_school_year_2010_2022`는 17개 열을 가진다. 두 키, 품질 상태 3개, 원천 레코드 수와 11개 보고 지표만 포함한다. 모든 11개 원천 지표는 7,277,987행 전부에서 공란 없이 0 또는 1이며, 비수치·음수·비이진 값은 0건이다.

학교–연도 집계에서 다음 불변조건을 적용한다.

- `reported_graduate_count = source_record_count`
- 보고 취업자 수는 보고 졸업학생 수 이하
- 건강보험 취업자와 교내 취업자는 각각 보고 취업자 수 이하
- 나머지 보고 지표는 각각 보고 졸업학생 수 이하
- 모든 원천 합계와 마트 합계가 정확히 일치
- 취업 학교–연도 키의 핵심 마트 미연결 0건
- 핵심 마트 결합 전후 행 수 24,044행, 조인 증식 0건

`취업자수 / 졸업학생수`는 공식 취업률과 같다고 보장할 수 없다. 제외 대상과 분모 정의가 연도별로 안정적이라는 근거가 없고, 2016–2019년 진학 지표도 신뢰할 수 없으므로 비율을 마트에 생성하지 않는다.

## 안전한 사용법

`_panel_year`는 실제 졸업 코호트가 아니라 원본 파일 연도다. 코호트 감사 결과 2014·2015년은 같은 2014 코호트의 서로 다른 파동이고, 2016–2021년은 실제 코호트보다 파일 연도가 1년 뒤이며, 2022년은 2021년 파일과 같은 2020 코호트다. 따라서 다음 쿼리는 원본 파일 연도별 품질 확인에만 사용하고 졸업 코호트 추세로 해석하지 않는다.

```sql
SELECT _panel_year,
       sum(employment_reported_graduate_count) AS reported_graduates,
       sum(employment_reported_employed_count) AS reported_employed
FROM analysis.school_year_core_with_employment_2010_2022
WHERE _employment_exists = 'true'
  AND employment_time_comparison_eligible
GROUP BY _panel_year
ORDER BY _panel_year;
```

코호트 분석을 준비할 때는 `data/metadata/edss_employment_cohort_year_audit.csv`에서 `cohort_analysis_eligible=true`인 파일만 선택하고 `inferred_cohort_year`로 재키잉한다. 단, 이 규칙을 구현한 최종 DuckDB 뷰가 생성되기 전까지는 수동 결합을 분석 결과로 배포하지 않는다. 진학자 수를 분석할 때는 `further_study_quality_status='as_reported'`도 적용한다. 취업 자료가 없는 16,986개 핵심 마트 행의 취업 지표는 `NULL`이며 0으로 대체하지 않는다.
