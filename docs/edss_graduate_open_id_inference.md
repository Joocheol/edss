# EDSS 대학원 OpenID 후보 추론

기준 실행일: 2026-09-02

## 결론

취업통계 2023–2024년의 일반·전문·특수대학원 학교-연도 2,435개에 대해 검토용 OpenID 후보를 생성했다. 대학알리미 이름 맥락이 유일하게 연결된 2,286개 중 1,805개(78.9589%)가 역방향 유일성 검사를 통과했다. 전체 대상 대비 74.1273%다.

후보 1,805개는 high 535개와 strong 1,270개다. 나머지 630개는 미해결로 보존했다. 이 결과는 공식 EDSS 교차표가 아니며 원본·제한 패널·정식 `개방ID`를 수정하지 않는다.

## 근거와 규칙

1. 대학알리미 2025 학과 API에서 대학원명·종류·지역이 유일하게 맞는 취업 학교-연도만 ID 비교 대상으로 삼는다.
2. ID 후보는 EDSS 대학정보공시 0402(일반대학원), 0403(전문대학원), 0404(특수대학원)의 정상 OpenID와 학과 집합에서 만든다.
3. 같은 연도 `0101` 기준표의 시도·본분교가 모두 맞는 후보만 비교한다.
4. 취업 학과 집합을 주 신호로, 대학알리미 2025 학과·주야간과 EDSS `0104` 학과·주야간을 보조 신호로 점수화한다.
5. 학과 3개 이상이 같은 해 하나의 후보와 완전일치하면 high로 분류한다. 작은 완전일치와 백테스트 임계값을 통과한 다중 신호 일치는 strong으로 분류한다.
6. 종류별 정상 ID 패널이 2023년에 끝나므로 2024년은 2023년 마지막 학과 서명을 사용한다. 단, 해당 ID가 2024년 `0101` 기준표에도 존재하고 지역·본분교가 맞아야 하며 신뢰도는 strong 이하로 제한한다.
7. 2023년과 2024년 후보가 충돌하면 제외한다. 같은 해 하나의 ID가 여러 대학원을 선택하는 역방향 충돌도 모두 제외한다.

## 결과

| 구분 | 학교-연도 |
|---|---:|
| high: 같은 해 학과 3개 이상 완전일치 | 535 |
| strong: 작은 완전일치 | 347 |
| strong: 전년도 완전일치 서명 + 현재연도 맥락 | 426 |
| strong: 마스킹 백테스트 임계값 통과 | 407 |
| strong: 2개년 동일 최상위 후보 앵커 | 90 |
| 선택 후보 합계 | 1,805 |
| 역방향 ID 충돌 제외 | 180 |
| 연도 간 후보 충돌 제외 | 6 |
| 기타 미해결 | 444 |
| 전체 | 2,435 |

연도별로는 2023년 high 535개·strong 377개, 2024년 strong 893개가 남았다. 2024년에는 같은 해 종류별 ID 패널이 없으므로 high를 부여하지 않았다.

## 마스킹 백테스트

정상 ID가 있는 2022년 `0104` 학과 프로필을 입력처럼 취급하고 ID를 숨긴 뒤, 종류별 패널에서 후보를 다시 찾았다. 1,195개 평가 프로필 중 1,079개를 선택했고 정밀도는 99.4439%, 커버리지는 90.2929%였다. 선택 임계값은 점수 0.60 이상, 1위와 2위 차이 0.03 이상, 공통 학과 1개 이상이다.

이 검사는 `0104`를 2023–2024 취업통계 입력의 대리 자료로 사용한다. 따라서 실제 대상에서 같은 정밀도가 보장된다는 뜻이 아니며, 후보 등급과 충돌 제외 규칙을 정하는 교정 근거다.

## 데이터 품질 판정

- 출력 행: 2,435
- 고유 `_school_identity_key`: 2,435
- 중복 키: 0
- 핵심 필드 결측: 0
- 정식 `개방ID` 대입: 0
- 입력·출력 SHA-256: `data/metadata/edss_graduate_open_id_inference.json`에 기록
- 상태: `review_required`

대학알리미는 2025년이고 대상은 2023–2024년이다. 학과 개폐·개명, 공시 패널 간 보고 단위 차이, 2024년 전년도 서명 이월이 남은 위험이다. high부터 학교 공식 대학원 페이지나 추가 공시 연도로 검토 승인한 뒤 별도 승인 목록을 만들어야 한다.

## 산출물과 재현

- 후보표: `data/metadata/edss_graduate_open_id_candidates.csv`
- 품질·백테스트 요약: `data/metadata/edss_graduate_open_id_inference.json`

- 실행·검산 노트북: `notebooks/graduate_open_id_inference.ipynb`

```bash
uv run --offline --with duckdb==1.4.1 python \
  scripts/infer_edss_graduate_open_id_candidates.py
```

원본과 DuckDB가 다른 저장소에 있을 때는 `--source-root`를 지정하고 출력은 현재 저장소 경로로 지정한다.
