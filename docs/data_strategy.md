# 데이터 수집 전략

## 1. 역사자료

EDSS 개방데이터의 전체 다운로드를 사용해 2009~2025년 패널을 우선 구축한다. 테이블별로 연도 범위와 항목 정의가 다르므로 하나의 거대한 파일로 바로 합치지 않고, 원천 테이블별 표준화 단계를 먼저 거친다.

## 2. 최신자료와 검증

대학알리미 Open API 결과는 다음 용도로 유지한다.

- 최신 공시연도 증분 갱신
- EDSS 다운로드 결과와 대학별 합계 대조
- EDSS에서 연도가 비어 있는 항목 보완 가능성 확인

## 3. 식별자

장기 패널에서는 대학 통폐합, 교명 변경, 본교·분교 및 캠퍼스 변경이 발생한다. 원본 학교코드를 보존하면서 별도의 영속 식별자를 구축하고, 변경 이력을 유효 시작연도와 종료연도로 관리한다.

## 4. 1차 완성 기준

- 우선순위 1 테이블 전체 다운로드
- 원본 파일별 체크섬과 행·열 수 기록
- 학교·연도·학과 키 중복검사
- 핵심 변수의 결측·0·비공개값 구분
- API와 2024~2025년 대학별 합계 교차검증
