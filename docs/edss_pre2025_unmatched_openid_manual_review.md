## 판정 규칙

1. `0101`의 최초·최종 연도와 연도 수를 기준으로 검토 순서를 정했다.
2. 고등교육·대학정보공시 전 패널에서 최종 관측연도, 패널 수, 행 수, 비영 숫자 셀, 학과명과 학과상태를 집계했다.
3. 같은 연도 KEDI 학교별 원본의 지역·학교유형·재적·입학·졸업·교원·직원·학과 수 후보를 대조했다.
4. 두 개 이상 학과의 정확한 집합이 같은 연도·지역의 이름 확인 ID와 일치할 때만 후계 후보 근거로 사용했다.
5. `폐과` 또는 KEDI `폐교` 근거가 있으면 폐교·폐과 계열 잔존 ID로 분류했다.
6. 0, 결측, 비공개, 해당 없음은 원천에서 서로 다른 값으로 유지했다. 이 표의 `latest_nonzero_measure_count=0`은 해당 최종 관측 행에서 숫자로 해석 가능한 비영 측정 셀이 없다는 뜻이다.
7. 후보 학교명은 신원 확정값이 아니다. 역사 ID를 현재 ID와 자동 병합하지 않는다.
