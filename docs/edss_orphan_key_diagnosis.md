# EDSS `0101` 미연결 학교연도 키 진단

기준일: 2026-09-01 (Asia/Seoul)

## 요약

`0101 고등교육학교개황`을 학교연도 기준 패널 후보로 놓고 15개 패널 13,640,746행을 재검사했다. 기존 검증에서 보고한 316은 데이터셋별 미연결 키 발생을 합한 값이다. 데이터셋 간 중복을 제거하면 실제 미연결은 76개 `(연도, 개방ID)`, 69개 `개방ID`, 8,106행이다. 전체 행의 0.0594%이므로 범위는 작지만, 이를 강제로 내부 조인하면 기관 경계연도의 자료가 체계적으로 탈락할 수 있다.

결론은 `review_required`다. 미연결 행을 삭제하거나 인접 연도 ID로 강제 매핑하지 않는다.

## 데이터와 grain

- 기준 데이터: `0101 고등교육학교개황`, 30,556개 고유 `(연도, 개방ID)`
- 비교 데이터: 나머지 14개 논리 패널
- 분석 grain: 서로 다른 `(연도, 개방ID)`
- 영향 행 수: 동일 키를 가진 원본 패널 행 전체의 합
- 제한 패널 처리: 취업통계에서는 키와 영향 행 수만 집계하고 개인 수준 열은 읽거나 출력하지 않음

## 검사 방법

1. `0101`의 학교연도 키와 ID별 최초·마지막·중간 관측연도를 구성했다.
2. 다른 패널을 스트리밍으로 읽어 `0101`에 없는 키와 영향 행 수를 집계했다.
3. 여러 데이터셋에 반복되는 같은 키를 하나로 합쳤다.
4. 동일 `개방ID`의 `0101` 관측기간을 기준으로 최초 등장 전, 마지막 등장 후, 내부 공백, 전 기간 미등장으로 분류했다.
5. `0101`의 반복키 1,187개와 최대 반복 수 4도 재확인했다.

재현 코드는 `scripts/diagnose_edss_orphan_keys.py`, 검토용 노트북은 `notebooks/edss_orphan_key_diagnosis.ipynb`다.

## 품질 판단

### 중간 위험: 시간 경계의 체계적 결합 손실

- 근거: 76개 고유 키, 8,106행이 `0101` 내부 조인에서 탈락한다.
- 영향: 기관의 최초·마지막 관측연도, 폐교·통폐합 전후, 조사범위가 다른 대학원 자료를 분석할 때 편향될 수 있다.
- 신뢰도: 키와 행 수는 높음. 신설·폐교·통폐합 같은 제도적 원인 판단은 낮음.
- 조치: 외부 교차표 검증 전에는 left join과 미연결 플래그를 사용한다.

### 높은 우선순위 검토: `0101` 전 기간 미등장 5개 ID

- 근거: 5개 키 모두 `0502 전체교원대비전임교원현황`의 대학원 행이며 영향은 8행이다.
- 영향: `0101`만으로는 해당 ID의 학교 속성이나 상태를 보완할 수 없다.
- 조치: 학교명·학교상태 교차표 또는 대학알리미 API로 ID 의미를 확인한다.

### 낮은 빈도지만 구조적 확인 필요: 내부 공백 1개

- 근거: 2015년 `개방ID=5831784427`이 `0316`과 `1016`에 각각 1행 있으나 `0101`은 2014년 다음 관측이 2020년이다.
- 영향: 인접 연도 보간이나 ID 승계 규칙을 자동 적용하면 잘못 연결할 수 있다.
- 조치: 2015~2019년 학교상태와 ID 변경 여부를 공식 자료에서 확인한다.

## 안전한 결합 규칙

- `0101`은 `(연도, 개방ID)` 반복키 1,187개, 최대 반복 수 4이므로 추가 차원 없이 일대일 학교연도 차원으로 사용하지 않는다.
- 다른 패널을 `0101`에 결합할 때는 left join을 기본으로 하고 `_0101_match_status` 같은 명시적 플래그를 둔다.
- 미연결 키를 삭제하거나 가장 가까운 연도의 동일 ID에 자동 대체하지 않는다.
- 학교명·본분교·지역·학교상태 교차표가 검증된 뒤에만 보정 매핑을 별도 테이블로 관리한다.

## 가정과 미해결 사항

- 시간적 분류는 관측범위의 차이를 보여 주지만 신설·폐교·통폐합·ID 변경을 증명하지 않는다.
- 일반 EDSS 패널 대부분에 학교명이 없어 현재 자료만으로 기관명을 확정할 수 없다.
- `개방ID`가 공식 학교 ID와 동일하다고 가정하지 않았다.
- 다음 우선순위는 전 기간 미등장 5개 ID와 내부 공백 1개 키의 외부 교차검증이다.
